# SAFT Tracker — Agent Performance & Progress Tracker

A web-based performance tracking system built specifically for **SAFT Advisory (SAFT KT IGNITE)** to replace manual whiteboard recording during weekly and monthly agency meetings. This system enables agents to update their sales metrics in real time, upload field activity photos, and automatically display the agency leaderboard.

🔗 **System / Live Demo Link:** [Click here to open SAFT Tracker](https://fadlanarif.github.io/SAFT-TRACKER/)

---

## ✨ Key Features

* **Real-Time Agency Leaderboard:** Automatically ranks agents based on their latest **Total TPC** and **YTD (TPC)** achievements.
* **Agent Metric Updates:** Agents can record and update their monthly performance metrics, including:
  * **P** — Presentation
  * **C** — Close Case
  * **Q** — Quotation
  * **NC** — New Contact
  * **BOP** — Recruits
  * **MTD (TPC)** & **YTD (TPC)**
  * **Total TPC** & **Total Cases**
* **Activity Log & Photo Uploads:** Agents can upload photo evidence of field activities (such as booths, client appointments, and awareness talks) with full-view modal support.
* **Agent Profile Management:** Agents can update their full name and profile picture directly from the dashboard.
* **Admin / Leader Panel:** Dedicated interface for agency leaders to register new agents using their **Agent Code**, update account details, reset passwords, and monitor overall team performance.
* **Responsive UI & Theme Toggle:** Supports both desktop and mobile views, complete with Light Mode and Dark Mode options.
